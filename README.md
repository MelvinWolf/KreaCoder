# Vibe Coding Games

Every team builds a small browser game in one afternoon, with an AI coding agent doing the coding.

## Getting started

1. Open this folder in VS Code.
2. Start your AI agent (Claude Code, Copilot, Codex, Cursor, ...) and tell it which team number you are, e.g. *"We are team 2, we want to make a game where ..."*.
3. Talk to it about your game, in any language. It takes care of everything technical, including saving and sharing your work with your team.
4. To play: open `games/<your-game>/index.html` in your browser and reload after changes.

All games online: see the GitHub Pages link in the repository's "About" section.
